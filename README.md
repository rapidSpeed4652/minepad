# MinePad
Minepad is a 4 key macropad with a rotary encoder. It uses VIAL, which is a fork of QMK firmware.

## Features
- 4 Cherry-MX keys
- 1 knob
- Support for mapping the keys and knob using VIAL

## CAD Model
It has two main parts and 8 small parts making the title and the logo. Made in Onshape!

## Firmware
I have used VIAL, a fork of QMK firmware, to make it possible to map keys using a web portal.
- Rotary encoder for volume
- One key for pause/play
- Another for mute

I will decide what I do with other keys later.

## BOM
Everything needed to make this macropad:
- 4x Cherry MX Switches
- 1x EC11 Rotary Encoder
- 4x 1u Keycaps
- 1x Seeed XIAO RP2040
- 1x Case (All printed parts)
